# rice_CRP_atlas
# This repository contains the source code for the integrative analysis of spatial transcriptomics and snRNA-seq data (rice CRP) described in the manuscript.

**System Requirements**
# OS: Ubuntu 20.04.1 LTS (Linux kernel 5.15.0)
# R Environment: R (≥ 4.2.0)
# Core Dependencies: Seurat (v4.3.0), DESeq2 (v1.38.3), clusterProfiler (v4.6.2), bluster (v1.8.0), ClustAssess (v1.0.0), SPOTlight (v1.2.0), Harmony (v1.2.4), Monocle3 (v1.4.26), CytoTRACE (v0.3.1), ComplexHeatmap (v2.26.1).
